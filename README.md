1. DESCRIPCIÓN DEL PROYECTO
El proyecto consiste en un sistema de librería desarrollado en Java con NetBeans, conectado a una
base de datos en MySQL. Su objetivo es gestionar información de libros, autores y editoriales mediante
una interfaz gráfica.
La aplicación permite realizar operaciones CRUD como registrar, consultar y eliminar libros, mostrando los
datos en una tabla. Además, utiliza una conexión JDBC para interactuar con la base de datos y un menú
principal para la navegación entre las opciones del sistema.
Este sistema aplica conceptos de programación orientada a objetos, bases de datos relacionales e
interfaces gráficas en Java.
